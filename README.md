# Smart-Library-Request-Workflow-in-ServiceNow

📌 Project Title:

Smart Library Request Workflow using ServiceNow

📖 Description:

The Smart Library Management System is designed to automate the process of requesting, approving, issuing, and returning books using ServiceNow. This system helps students request books easily and allows librarians to manage approvals and book availability efficiently.

🎯 Objectives:
Automate book request process
Manage book availability
Implement approval workflow
Track book issue and return status
Improve efficiency and reduce manual work

🏗️ Modules Used:
Service Catalog
Flow Designer
Tables & Dictionary
User Administration (Roles)
Notifications
